# Predicción de Riesgo de Fracaso Académico

Proyecto de análisis de datos enfocado en predecir el riesgo de fracaso académico en estudiantes utilizando algoritmos de aprendizaje automático (Machine Learning), analizando factores de estilo de vida, salud mental y hábitos de estudio.

## Tecnologías y librerías usadas
* Python
* Pandas, Scikit-Learn
* Modelos probados: Regresión Logística Multinomial, Árboles de Decisión, SVM y Random Forest.
* Técnica de balanceo: SMOTE.
